3차 단위 프로젝트
프로젝트명 : 

주제 : LLM 을 연동한 내외부 문서 기반 질의 응답 시스템

· 환각을 방지하고 원하는 내외부 데이터 내에서 RAG 기반 LLM 활용 질의 응답 시스템 구현
· 문서를 벡터 형태로 임베딩하여 벡터데이터 베이스에 저장 및 검색
· LangChain을 활용하여 벡터데이터베이스와 LLM 연동

질문의 의도와 방향성을 내부문서에서 찾을수 있으면
    내부문서 -> 내부문서 ->chromadb -> langGraph(tool->MCP) -> LLM 답변
없으면    
    외부문서 -> api호출(MCP), 크롤링 

목표:
가장 기본적인 RAG 시스템의 동작 검증
내부 문서만으로 질의 응답이 가능한 MVP 완성

구현범위:
1. 문서처리 파이프라인
2. 벡터데이터베이스 구축
3. 기본 검색 및 답변 생성
4. 간단한 인터페이스(옵션)

검증:
10개 이하의 내부문서로 벡터Db 구축
테스트질문 5개에 대해서 문서기반 답변 생성
문서에 없는 정보 질문시 정보없음 응답(환각방지)
답변에 출처 표시
